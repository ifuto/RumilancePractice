実装メモ

  • タイトル: settings.scoreboardServerName()（金の✦を前後に付与）。Objectiveディスプレイ名は白。
  • 1行目は常に Online / Queue / Match のサマリー。Queue は queueService.totalWaiting()、Match は matchRegistry.activeCount()。
  • 統計ブロック: Elo（全キット中の bestElo）、Wins/Losses、K/D、Streak（bestStreak）、Matches、Kits。3秒キャッシュ。
  • キュー中: 統計の上に Queued: <kitId> (ランク/アンランク) と Wait: Xs Queue: N を2行追加。
  • 試合中: あなた（§c赤／§9青のどちらか自分のチームカラー）と相手を ▸ YOU / ▸ OPPONENT バナー付きで表示。
  • シリーズスコア: Score: myWins - oppWins。再戦ボタンによる連続試合のみ加算。
  • キット・モード・キル数・K/D・経過時間を表示。
  • 最下行は常に settings.scoreboardServerIp() をアクア色で表示（§b）。
  • 非対応: スコアボード上でのキルタイトルやマッチリポートへの導線は今のところ無し（リポートはチャットと /matchreport のみ）。
