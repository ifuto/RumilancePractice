# GUI Design Reference (from gui.json)

`gui.json`(ルート)は外部GUIビルダーからのエクスポート。9カラム×6行のチェストGUI、
計7画面を収録(ファイル末尾は途中で切れており、Spectate以降の画面は欠落)。
以下は各画面のレイアウト要約と、そこから読み取れるデザイン規約。

## デザイン規約(共通)

- **枠**: 画面ごとの色付き色付きガラス板で**全周枠**(0行目・5行目は全列、1〜4行目は0列目と8列目)。
  色は画面のテーマごとに違う(白/ライム/空色/黄/緑)。
- **タイトル**: (0,4) にテーマに合ったアイコン + カスタム名
  (例: チーム一覧=ネザライト鍛冶型、パーティー=名札、対戦メニュー=ネザースター、観戦=エンダーアイ)。
- **コンテンツ**: 1〜4行×1〜7列。内側の空きは**埋めずに空白**(黒フィルは使わない)。
  配置は中央寄せ・間隔広め(列2と列4を軸にした2カラム構成が多い)。
- **閉じる/戻る**: (5,4) にバリア「Close」または矢印「Back」。
- **ページ送り**: 矢印「←」(4,1) /「→」(4,7)、または最下行両端 (5,0)/(5,8)。
- **メンバー表示**: プレイヤーヘッドを1行7個(列1〜7)。
- **チーム表示**: 赤羊毛/青羊毛 + 名前に人数入り(例 "Red Team (3Players)")。
- **権限ロック**: バリア + 「VIP can only add team more」等の説明。
- **未開放枠**: 薄グレーガラス板「Not Available Team」。

## 画面別レイアウト(9カラム表記、.=空き)

### Team List(チーム一覧)— 白枠
- (0,4) 鍛冶型「Team List」
- 1行目: 赤羊毛・青羊毛(チーム+人数) / ライム板「Add Team」/ バリア×2「VIP…」/ バリア×2「VIP+…」
- 2〜4行目: 左2列に 金リンゴ「Max Health」×2 → 革チェスト「Body Size」×2 → ポーション「Effect」×2、
  右5列は薄グレー「Not Available Team」
- (5,4) 矢印「Back」

### Player List(プレイヤー一覧)— 白枠
- 0行目: 赤羊毛・青羊毛(チーム切替) … (0,8) ダイヤ剣「Random Team」
- 1〜3行目: ヘッド×7 のロスター
- 4行目: 「←」(4,1) ヘッド5個 「→」(4,7)
- (5,4) 矢印「Back」

### Party Hub(パーティーハブ)— 白枠
- (0,4) ホストのヘッド「Party Hoster's Head」
- 中央まばら配置: (2,2) ヘッド「Player List」/(2,4) 鍛冶型「Team List」/(3,2) 本「Select Kit」/(3,4) ダイヤ剣「Start Battle」
- (5,4) バリア「Close」

### Party(パーティー作成)— 白枠
- (0,4) 名札「Party」
- 2行目: (2,1) ライム染料「Create Public Team」/(2,3) 樫看板「Public Team List」/(2,5) 灰色染料「Create Private Team」
- (5,4) バリア「Close」

### Kit Editor(キット編集)— 黄枠
- (0,4) 本(キット名)
- 1行目(列1〜7): ダイヤ剣/ダイヤ斧/ネザライト剣/ネザライト斧/金リンゴ/エンダーパール/エンドクリスタル
- 2行目: メイス、紙
- 5行目: 両端に矢印(ページ)、中央バリア「Close」

### Battle Menu(対戦メニュー)— 空色枠
- (0,4) ネザースター
- 内側まばら: (1,2) ダイヤ剣/(1,6) 鉄剣/(2,4) ヘッド(相手)/(4,2) エンドクリスタル/(4,6) 本
- (5,4) バリア「Close」

### Spectate(観戦)— ライム枠(最下行のみ緑板アクセント)
- (0,4) エンダーアイ
- 内側は空(動的リスト領域)
- 5行目: 両端矢印、(5,3)/(5,5) 緑板、中央バリア「Close」

## 現行実装との差異(参考時点)

現行 `MenuScaffold.chrome` は0行目・5行目のみ黒埋め+中央ナビの「ダークバー」方式で、
内側は空白。gui.jsonの案は「全周色枠+内側完全空白+テーマ色」方式。
採用する場合は画面ごとの枠色・タイトルアイコン・ボタン配置を上記に合わせる。

## 対応する既存GUIクラス

| 画面 | クラス |
|---|---|
| Team List | TeamHubGui / TeamsBrowserGui / TeamSettingsGui |
| Player List | PlayersGui |
| Party Hub / Party | PartyInviteGui(およびパーティー系フロー) |
| Kit Editor | EditKitGui |
| Battle Menu | BattleMenuGui |
| Spectate | SpectateListGui |

※ gui.json は Spectate の途中で切れている(末尾が `},` で閉じていない)。
追加画面がある場合は再エクスポートが必要。
