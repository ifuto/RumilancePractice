# N Arena — 機能一覧

Paper 1.21.11 向け Practice PvP プラグイン **N Arena**(プラグイン名 `NARENA`、データフォルダ `plugins/n-arena`)の全機能インベントリです。

## 対戦・ゲームモード

### デュエル(決闘)
- `/duel` — 1v1 決闘の申請。`/accept` `/deny` `/cancel`
- 申請GUI(相手・キット・マップ選択)、マップ選択GUI(DuelMapSelectGui)
- 決闘ID・決闘ログの永続化(duel パッケージ)

### キュー
- `/queue` `/ranked` `/unranked` — ランク戦 / アンランク戦キュー
- キット別キュー、キュー有効/無効、メンテナンスモード
- Ping 上限(ランク戦)、プラットフォーム分離(Java / Bedrock)、自動再キュー
- 待機中は離脱アイテム(赤色の染料)配布 + アクションバー表示
- `/leave` でキュー離脱
- **看板キュー**: ロビーの看板から参加できる Unranked Queue。看板ごとにキット固定(設置時に選択)、カスタム(オリジナル)キット対応。2人目は1人目のキット内容で対戦。看板アイテムは `/practiceadmin sign <kit>`(OP) または管理GUIの「看板キット」から取得して設置

### チーム(パーティ)戦
- `/team` — パーティ作成・招待・参加。最大15人/チーム
- チームハブ・チームカラー(羊毛トグル)・チームマーカー(色付き ●)
- チーム用オリジナルキット戦闘(キット内容=パーティの物、ルール=グローバルキット)
- チームカラーアーマー、敵透過表示抑制(TeamGlowLos)、パーティホットバー

### FFA
- `/ffa` — 常設 FFA エリア。アリーナ選択・リスポーン・スポーン分散
- デス→ロビー戻り、戦闘ログ

### プラクティス
- `/prac` `/practice` — ソロ練習モード。アンカー・TNT・マスの練習台
- 練習ボット(PracticeBotGui)、レイアウト編集(PracticeLayoutGui)

### 試合エンジン
- カウントダウン(開始ロック)、試合再生成、勝敗判定、タイムアウト引き分け
- 切断=敗北、強制終了/強制開始(管理者)、観戦モード
- 体力表示 `{数字(最大20)}♥`(小数1桁・吸収時黄色)

## キット・アイテム

- **キット**: `/kit` 選択GUI、キット編集、プレビュー、金床リネーム(制限あり)、プリセット
- **オリジナルキット**: `/originalkit` — 自分で編集して保存するカスタムキット。スロット別管理、差分(デフォルト比)保存、プリセットは免除
- **オリジナルキット専用部屋**: 編集は専用の物理部屋(クリエイティブ、他プレイヤーから非表示・当たり判定なし)。設定は `/ekitadmin spawn`(部屋の中で実行)+ 管理ツールで範囲選択して `/ekitadmin region`。部屋の「保存ボタン」(看板ボタン、置くと自動登録)で保存して退出。未設定時は編集に入れず案内メッセージのみ(インベントリは壊れない)
- **Ekit(イベントキット)**: `/ekit` + 管理者用編集/コピー/選択GUI
- 防具トリム(スミシング台GUI)、エンチャント/ポーション選択、ゴールデンヘッド、トーテム
- **カスタムシールド**: 管理GUIでパターン編集(最大6レイヤー)、カスタムモデルデータ配信
- ロビー機能アイテム(コンパス・離脱アイテム等)、アイテムフローガード

## ランク・統計・ランキング

- **ELO レーティング**(ランク戦)+ スキルレーティング/ティア
- **ランク**: `/setrank`、ランクアイコン(リソースパックのフォントグリフ、`/rankicon`)
- **隠しランク**: `/urank`(指定プレイヤーのみ)
- **リーダーボード**: 月間キルランキング、年間最多連勝ランキング、個人ボード(5m以内でプレイヤーの方を向く・イーズアウト回転)、`/lbspawn`
- `/stats` `/kdr` `/profile`(プロフィールGUI)、`/matchhistory`(試合履歴GUI)
- **称号**: `/title`(称号GUI)、キル称号、ネームカラー(上位ランクは3日に1回変更制限)

## コスメティック

- アローエフェクト(`/arroweffect`)、キルエフェクト(`/killeffect`)
- 防具トリムコスメティック、ネームカラー、ヘッドフォント(頭上タグ)

## 運営・モデレーション

- **BAN**: `/ban` `/unban` `/banlist` `/testban`、ログイン遮断スクリーン
- **チャットBAN**: `/chatban` `/chatunban`、スパムフィルター
- **キック**: `/kick` `/testkick`
- **通報**: `/report` `/reportlist` `/objection`(異議申立)
- **リプレイ**: `/replay` — 試合の録画・NPC再生、アーカイブ
- **試合調査**: `/matchinv`(試合時のインベントリ参照)、`/matchreport`
- **試合強制操作(OP)**: `/forcematch <player1> <player2> <kit> [arena]` — 双方が戦闘可能な場合に対戦を強制開始(`[arena]` 省略時はランダム、`random` も可)。`/forceend <player>` — 対象の試合を引き分けで強制終了
- **管理GUI**: `/practiceadmin menu` で直接開く、または `/practiceadmin tool` で配布されるネザースターを右クリック。キット/アリーナ/プリセット/eキット/看板キット/リソースパック方針などをここから管理
- `/checkid`(プレイヤーID照合)、プレイヤーデータGUI、プレイヤー検索、`/admin` `/practiceadmin`
- **看板保護**(看板の不正編集ガード、`/signcheck`)、`/walltext`(壁面テキスト装飾)
- `/rumireload`(設定リロード)、`/packpolicy`(リソパ方針をコンソールから切替)

## リソースパック

- サーバー側から自動配信(参加10tick後)、SHA-1 検証
- **必須 / 推奨ポリシー**: 管理GUI + `/packpolicy` で実行中切替、`pack-policy.yml` に永続化
- 未適用プレイヤーは **N / N+ / OWNER テキストバッジ**で表示(閲覧者ごと)
- ランク/チームアイコン、カスタムシールド、機能アイテムアイコンをグリフ配信
- パックは常にクライアント選択リストの一番上にピン留め

## プラットフォーム・統合

- **多言語対応**: 日本語・英語(米/英)・韓国語・中国語・スペイン語・フランス語の7言語。`/lang` で切替、初回参加時に言語選択GUI
- **Lunar Client**: Apollo リッチプレゼンス連携
- **Bedrock(Geyser)対応**: 参加検知、プラットフォーム別マッチング
- **TAB(プレイヤーリスト)**: 試合中はチーム別の縦列に自動整列(チーム順に列、列内は名前順、観戦者は下部)。少人数でも列が分かれるよう、各チーム列の間に**空白パディング**(透明な埋め草プレイヤー、実体なし・スキン/チャット/コマンドに影響なし)を自動挿入。チームカラー・ランクバッジ・チームマーカー表示、ロビープレイヤーは試合参加者から非表示。1.21.2+ のリスト順序インデックス+ProtocolLibで実現(`match.tab-columns-enabled`、パケットパッチャー系プラグインは自動検出して無効化、ProtocolLib未導入時は列分けのみで空白なし)
- **ProtocolLib**: カスタムモデルデータ・パケットレベルの見た目制御

## ロビー・ワールド

- `/lobby` `/spawn` `/hub` `/slobby` — ロビーテレポート、スポーン設定
- **座り**: ロビーでボトムハーフブロック/下付き階段を右クリックすると着座(階段は向きに合わせた自然な姿勢)
- ロビーコンパス(機能メニュー)、ロビー保護(アイテムドロップ/拾い禁止等)
- スコアボード(試合中/ロビー表示)、MOTD、サウンド設定(`/setting`)
- 視点設定(エンティティ表示制御)、個人用ワールドボーダー、ワールド別描画距離
- 進捗・爆発・飛び道具などの競技用挙動調整

## 技術基盤

- プレイヤー状態機械(ロビー/キュー/試合/観戦/…)、セッション管理
- SQLite データベース(統計・レイアウト・コスメティック等のリポジトリ)
- 非同期ワーカプール、設定サービス(プレイヤー設定値を保持する安全リロード)
- 看板・ブロック操作のガード、セキュアな署名変更監視
