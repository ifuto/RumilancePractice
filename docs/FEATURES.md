# N Arena — 機能一覧

Paper 1.21.11 向け Practice PvP プラグイン **N Arena**(プラグイン名 `NARENA`、データフォルダ `plugins/n-arena`)の全機能インベントリです。

## 対戦・ゲームモード

### デュエル(決闘)
- `/duel` — 1v1 決闘の申請。`/accept` `/deny` `/cancel`
- 申請GUI(相手・キット・マップ選択)、マップ選択GUI(DuelMapSelectGui)
- 決闘ID・決闘ログの永続化(duel パッケージ)

### キュー
- `/queue` `/ranked` `/unranked` — ランク戦 / アンランク戦キュー
- キット別キュー、キュー有効/無効、メンテナンスモード
- Ping 上限(ランク戦)、プラットフォーム分離(Java / Bedrock)、自動再キュー
- 待機中は離脱アイテム(赤色の染料)配布 + アクションバー表示
- `/leave` でキュー離脱
- **看板キュー**: ロビーの看板から参加できる Unranked Queue。看板ごとにキット固定(設置時に選択)、カスタム(オリジナル)キット対応。2人目は1人目のキット内容で対戦。看板アイテムは `/practiceadmin sign <kit>`(OP) または管理GUIの「看板キット」から取得して設置

### チーム(パーティ)戦
- `/team` — パーティ作成・招待・参加。最大20人/チーム（1サイド）
- チームハブ・チームカラー(羊毛トグル)・チームマーカー(色付き ●)
- チーム用オリジナルキット戦闘(キット内容=パーティの物、ルール=グローバルキット)
- チームカラーアーマー、敵透過表示抑制(TeamGlowLos)、パーティホットバー
- **キット編集中のパーティ戦開始**(ITEM 44): 編集中メンバーは下書きを強制保存
  (月制限を貫通)して編集室を退出し、開始を妨害しない

### FFA
- `/ffa` — 常設 FFA エリア。アリーナ選択・リスポーン・スポーン分散
- デス→ロビー戻り、戦闘ログ
- **`/bot`(FFA内)= マネキン練習台**: FFA アリーナ内での `/bot` は Quantum BOT ではなく
  **マネキン方式のダミー**を出す(`FfaMannequinService`)。
  - **既定 OFF・アリーナ単位の任意 ON**: `/practiceadmin` → FFA Config → アリーナの
    **`FFA Bot`** トグル(`ffa.yml` の `arenas.<id>.settings.bot`)で有効化する。
    OFF のアリーナでは `/bot` はマネキンも Quantum BOT も出さず、どこで ON にするかを案内する
    (新規作成アリーナも OFF)
  - 装備: **不可壊(耐久無限)のネザライトフル装備** — 全身 Protection 4、
    **レギンスだけ Blast Protection 4**。**両手にトーテム**(`TOTEM_OF_UNDYING`)
  - ネームタグ: **太字・水色の `NARENA BOT`**(常時表示)
  - 出現位置: 視線方向 2 ブロック先(自分の方を向く)。アリーナに region があれば内側にクランプ
  - **ダメージは全部そのまま受ける**: クリスタル・リスポーンアンカー・ベッド・TNT・矢・ポーション・
    近接を、**所有者でも他人でも**区別せずバニラの計算どおり通す(攻撃者フィルタも帰属解決も無し)。
    他プラグインがキャンセルした frame は開け直すので、グローバルな保護で無敵化しない
  - **倒せない**: 両手のトーテムでバニラ本来の POP(音+パーティクル+消費→HP半分)が走り、
    直後に両手へ補充。手が空になった場合も死亡を握りつぶして体を再生成
    (キャンセルされた致命傷を生き延びた Mannequin はクライアント側で固まるため)
  - VOID 落下だけはキャンセルして所有者の元へ戻す(アリーナの外へ落ちると二度と戻せないため)。
    3 秒無被撃で毎秒 1 HP 回復(最大 20)
  - **再度 `/bot` で削除**。アリーナの FFA Bot を OFF にした時点・FFA 退出・試合への引き抜き・
    ログアウト・プラグイン停止でも消える(`setPersistent(false)` なのでディスクには残らない)
- **`/bot`(FFA外)= Quantum BOT**: 従来どおり同梱マップの実 BOT をスポーン

### プラクティス
- `/prac` `/practice` — ソロ練習モード。アンカー・TNT・メイスの練習台
- **Battle Menuの「ボット」**(ITEM 44): 5モード選択画面(クリスタル/ネザポット/メイス/
  カートPvP/ソード)。各タイルに運営が紐づけたキット・空き部屋数を表示し、空いている
  部屋へ入室
- **対戦ボット部屋**(ITEM 41/44): `/practice draft <名前>
  <ANKER|MACE|SWORD|CRYSTAL|NETHERITE_POT|CART>`
  → `pos1`/`pos2` → `selection apply` → `p1` → `botpos`(任意) → `save` → `enable`
  - **試合と同じ流れ**(ITEM 44): 待機(時間/難易度/設定)→カウントダウン→戦闘→
    勝利/敗北/引分タイトル→60秒でロビー。複数人の同時Bot戦もセッション単位で独立
  - **キット紐づけ**(運営必須): `/practice bindkit <モード> <キット|clear>` —
    practices.ymlの `bot-mode-kits` に保存。試合開始時に紐づけキットを適用、
    未設定ならモード標準装備(コンソールに警告)
  - **マップ紐づけ**(ITEM 44): `/practice bindmap <モード> <部屋|clear>` —
    そのキットに紐付いたマップ(練習部屋)で試合する(`bot-mode-rooms` に保存)。
    未設定ならモード内の最初の空き部屋
  - **時間制限は10分固定**(600秒)。判定がつかないまま10分経過で引き分け
  - **難易度**(BotDifficultyGui、プレイヤー単位で保存): 配布マップ準拠プリセット
    (NPC/イージー/…/サバイバルマスター)+詳細パラメータ(攻撃力/攻撃間隔/移動速度/
    回復/コンボ間隔/シールドスタン/シールド軽減/トーテム目標)。practices.ymlの
    `bot-difficulty` に永続化。**マップ実数値準拠**(quantum:difficulty/0..6を全行抽出):
    1発の威力は全ラング共通の本物の剣撃(8・バニラ経路)、移動は全ラング走行同等、
    難易度は**攻撃間隔・エイム・回転速度・トーテム間隔**で表現。**Botの最大体力は
    全難易度でプレイヤーと同じ20、攻撃リーチもプレイヤーと同じ3.0ブロック**。
    メイススマッシュの落下スケールはバニラ式そのまま
  - ソードBot: 追跡+左右ストレイフで斬りかかる、シールド構えで被ダメ半減+
    殴り返すとスタン、3秒無被撃で回復(すべて難易度依存)
  - ネザポットBot(ITEM 44): 剣AI+体力50%割れで回復ポーション、近距離の相手に
    有害ポーション
  - カートPvP Bot(ITEM 44): 弓で牽制しつつ距離を取り、着火TNTを転がしてくる
    (配布マップのTNTトロッコモードをアレンジ。爆発源=BotでBotは自爆無効)
  - クリスタルBot: マップg1gc実装に全面準拠 — 2m以内で足止め・超えたら前進(壁はホップで
    登る)、3m以内から**本物の剣撃**(8ダメージ・全難易度350ms固定間隔・プレイヤーの
    無敵時間が切れた時だけ)、crystal_cd梯子(300/300/300/150/100/150ms)で黒曜石台+
    エンドクリスタルのコンボ。**リスポーンアンカーは全難易度で使用**(近接圏外で
    設置→充填→爆発のサイクル: anchor_cd 250/200/200/150/50/50ms→charge_cd
    250/200/150/100/100/100ms→爆発(威力5+着火)→explosion_cd休止・アンカー破壊で
    中断)。トーテムポップ後は**totem_cd梯子分の休止**(Easy 2秒〜Master同tick復帰)。
    HP20・回復は金リンゴのみ(HP80%で手に持って1.75秒実食→+8HP/5s・吸収2・2個/命)。
    プレイヤーが箱囲いすると**頭上/足元の床/間の壁を採掘**(1.5秒/ブロック)。全アクションで
    マップ同様に**ホットバー可視切替+手振り**(剣/クリスタル/黒曜石/アンカー/グロウストーン/
    金リンゴ/パール)。
    勝利条件はトーテムポップ数が目標に到達すること
  - クリスタル/カート部屋は爆発ダメージがプレイヤーにも通る(自クリ誤爆・TNT含む)
- `/practice botpos <名前> [clear]` — アリーナ内のBot出現位置を運営が設定(全Bot種対応)
- 練習ボット設定(PracticeBotGui: シールド切替)、レイアウト編集(PracticeLayoutGui)
- Bot戦の開始/結果と通常試合の結果はコンソールにも記録(`[N Arena][BotMatch]` /
  `[Match]` プレフィックス)
- **AFK練習の入口は1つ**: `/afkcrystal`(`/afkc`)。旧9x9トーテムBOT部屋(`/afkpractice`
  `/afkp`)は廃止され、**`/afkpractice` `/afkp` `/afk` はすべて `/afkc` の別名**として
  同じAFK BOT Crystalの部屋を開く(サブコマンドもそのまま `start|stop|kit|settings|reset`)
- **AFK BOT Crystal**(`/afkcrystal` `/afkc`): クリスタルPvP練習用の新BOTタイプ。
  100x100ネザライト床を自動生成し、BOTはフル装備(ヘルメット/チェストプレート=
  Protection IV、レギンス/ブーツ=Blast Protection IV(最大)、全パーツに火炎耐性+
  耐久無限=Unbreakable、更にFire Resistance無効化)。
  - **常にトーテム**: BOTはトーテムを保持し、致命傷で**バニラ本来のトーテム発動**
    (本物のエフェクト+手から消費+ハート半分で復活)→**即時補充**のため倒せない
    (体力はしっかり減り、名前欄にリアルタイム表示)。万が一死亡が成立しても
    プラグインが死亡を握りつぶしてBOTを即再生成(**BOTが消えることはない**)
  - **オフハンドの盾ON/OFF**(設定GUI `/afkcrystal settings` またはホットバーの
    コンパレータ): ONなら正面の攻撃/投げ物/爆発をバニラ同様ブロック
  - **盾の復帰時間**: 斧で割られた盾が戻るまで **2秒 / 5秒(デフォルト)** を選択可能。
    プレイヤーの盾もBOTの斧で無効化される(バニラ相当)
  - **リセットボタン**: プレイヤースポーン地点中央のボタンで「キット全再装填+
    置きブロックの一掃+BOTの位置・体力・エフェクト・盾の状態を初期化」
    (`/afkcrystal reset` でも可)。**プレイヤーが死亡してもBOTは初期化されない**
    (エリアとキットだけ復元。BOTのリセットはボタン/リキットの明示時のみ)
  - **建築自由(個数・半径制限なし)/ 高さ上限は30ブロック**: アリーナ内ならどこでも
    何個でも設置可。**設置できる高さは床から30ブロックまで**で、それより上は設置だけ
    拒否される。**この30はブロックの設置高さのみの制限で、プレイヤーの移動制限では
    ない**(境界テレポートは廃止。床の外へ出る・高く登るのは自由で、VOID落下だけは
    スポーンへ救助)。
    **リセット(ボタン/リキット/死亡)はアリーナ全面を設置上限(+旧上限分の余裕)まで
    ボタン以外全部空気に一掃**するので置いたブロックは必ず元に戻る。ネザライト床と
    ボタンのみ破壊不可(爆発でも消失しない)。水晶爆発の自傷ダメージは本物通りに通る。
    **ウィンドチャージは地面に向かっても投げられる**(インタラクト握り潰しの再武装)
  - BOT戦とキットの紐づけは2系統: **`/botadmin <SWORD|MACE|CRYSTAL|NETHERITE_POT|CART>
    <キット>`**(装備の紐づけ。例: `/botadmin mace mace`。タブ補完で候補表示。`off`で解除)
    と `/practice bindkit <モード> <キット>`(同一ストアなのでどちらでも可)、
    **`/botadmin <botkit> <arenakit>`**(開催アリーナ側の紐づけ。同一キットも可)。
    引数なしで両方の紐づけ一覧を表示
  - **キット紐づけ(運営)**: `/afkcrystal bindkit <kit|list|clear>` でサーバーキットを
    **最大5個**まで紐づけ(`/afkcrystal unbindkit <kit|all>` で解除、
    afk-crystal-settings.yml に永続化)。紐づけがある間、部屋のキットは**キット選択GUI**
    になり、選択したキットが**試合と同じ方式**(KitLoadout適用)で装備される。
    スポーン中央ボタンの再装填(rekit)・リスポーンでも選択キットが再装備され、
    選択はプレイヤー単位で記憶される。未紐づけなら従来どおり個人キットエディタ
  - AFK BOT CrystalのBOTは**攻撃してこない**(ノックバックで100x100の床どこへでも
    移動する。端に出た時だけ定位置へ戻る)。盾ON時は**常にプレイヤーの方を向き、
    盾を実際に構えるポーズ**(Paper Mannequinのアイテム使用ポーズ)。斧で盾を割った
    打撃分のダメージも通る。体力は**常に20**(バニラ範囲)。浮遊した場合は
    **その場で床に着地**、BOTが消えても自動で再生成。ホットバーの専用スロットは廃止。
    キット=`/afkc kit`、設定=`/afkc settings`
  - **全員別々の専用アリーナ**: 入室ごとに自分の固定アンカー(+60kライン)へ完全
    再生成。死亡時・中央ボタンでも**アリーナごと初期化**(建築も元通り)
  - **落下ダメージ・クリスタル/アンカーの自傷は本物**(落下溜めクリスタルが機能)。
    BOTへのクリスタル爆発も通る(他リスナーがキャンセルしても復活させる)
  - トーテムポップ時も**ノックバック/ウィンドチャージのノックを再適用**(無効化されない)。
    ポップ後は**BOTを再生成**して凍結を防止(キャンセルされた致死ダメージを通した
    Mannequinはクライアントが死亡判定して操作・KBを一切受け付けなくなるため)。
    ポップ直後の体力はハート半分(1HP)。実際にトーテムを持っている致命傷は
    **バニラ本来のトーテム発動**(本物のエフェクト+消費+ハート半分で復活)で、
    死亡ネットにより**BOTが消えることはない**
    入室時に**装備一式を自動配布**(最初の装備適用で破棄されるloaner)
  - `/afkc stop`・`/hub`・`/lobby` で**いつでも中断してロビーへ**(LobbyServiceの
    実ロビー復帰を呼ぶ)
  - **`/hub` `/lobby` `/spawn`でAFKセッションは終了**してロビーへ戻る
    (アリーナの境界ガードにロビーから強制送還されない)
  - **入室排他**: FFA参加中・コンバットタグ中・デュエル/試合中・観戦中・キュー中・
    プラクティス中は`/afkcrystal` `/afkc`に入室できない(逆にAFKセッション中は/ffa参加不可)
  - **AFKセッション中は完全なプライベート部屋**(ProtocolLib)。入室した瞬間から
    **自分の範囲(100x100の床)以外のブロックパケット(チャンク/ライト/ブロック更新/
    ブロックエンティティ/破壊アニメ)とエンティティ・プレイヤーパケットは遮断**され、
    他の人がafkcしている部屋は一切見えない(逆方向も同様: AFK中のプレイヤーは
    部外者から不可視)。Bukkit側の `hidePlayer` 相互非表示も併用。退出で復帰。
    Battle Menuには**No move bot**タイル(=afkc)を追加
  - **AFK部屋ではロビー保護が掛からない**: ブロックの設置/破壊・アイテムの
    ドロップ/回収・ダメージ(落下・自傷)が非OPでも普通に機能する
    (`rumilance.lobby.bypass` 不要)
  - 装備の右クリックTrim画面は**Kit Edit限定**(AFK部屋では出ない)

### 試合エンジン
- カウントダウン(開始ロック)、試合再生成、勝敗判定、タイムアウト引き分け
- 切断=敗北、強制終了/強制開始(管理者)、観戦モード
- 体力表示 `{数字(最大20)}♥`(小数1桁・吸収時黄色)

## キット・アイテム

- **FFA コマンドゲート(デフォルトOFF)**: `/practiceadmin ffacommand <on|off|add|remove|list|clear> [command]`
  で管理。ONにするとFFA中は**ホワイトリスト登録コマンドのみ**使用でき、しかも**コンバットタグ外のときだけ**
  (戦闘中は全コマンドブロック)。OFFならFFAのコマンドは従来通り無規制。設定は ffa.yml の
  `command-whitelist` に永続化。
- **コンバットタグ通知**: FFAで戦闘状態に入ると赤文字で **You are now in Combat**、
  タイマー切れまたは死亡で解除されると黄緑で **You are no longer in Combat**。
  **戦闘中の相手をキルすると自分のコンバットも即解除**。
  **自分自身のダメージ(自クリスタルの自爆等)ではコンバットタグは付かない**。
- **クリスタルFFAは参加時に無配布**: アリーナに入っても装備は出ない。チャットで
  **Select your kit with /k** を表示。**/k** で **KIT1〜9のボタンGUI**(クリックで即装備、
  選択スロット更新)が開く。キルしても無料再配布なし(自分のHP/残弾のまま継戦)。
  **死亡→FFA復帰後はインベントリ空なので /regear がフル補充として機能する**。
- **クリスタルFFA専用コマンド(コンバット外のみ・クリスタルFFAアリーナ限定)**:
  - `/regear` — 最後に選択したKIT1〜9の中身で**補充**(装備[防具/盾]とトテムは対象外)
  - `/repair` — 手持ちアイテムの耐久をMAXに
  - `/heal` — 体力MAX・着火消し・ポーションエフェクト全削除
  - `/k1`〜`/k9` — そのKITスロットの中身でインベントリを**置換**(選択スロットも更新、
    リスポーンもそのKITになる)
  - 管理者のコマンドゲート(`/practiceadmin ffacommand`)がONの間は、これらも他コマンドと
    同様にホワイトリスト登録が必要。

- **Crystal FFA Kit 申告(存在する場合のみ)**: 管理GUIの設定画面に「Crystal FFA」タイル
  (エンドクリスタル)。1キットだけ申告でき、申告したキットは `/ekit` で選ぶと専用の
  **縦4GUI**(行1/2/4=**灰色の板ガラス** / 行3=**エンダーアイ9個**)が出る。
  **行3のN番目のエンダーアイをクリックするとKITnの編集を直接開始**(選択なしでOK)。
  各スロットは同じcrystalキットの
  **別々の配置**を保存できる。選択は `crystal-ffa.yml` に永続化、配置は
  `<kit>#v<1..9>` として保存。
- **爆発ダメージ**: Paperは爆発のソース(発生源)エンティティを自分の爆発から守る
  (PaperMC/Paper#11167・仕様)。Paperはクリスタル爆発のソースを**叩いたプレイヤー**にするため、
  クリスタルのセルフダメージだけは**源泉なし爆発への変換**(ヒット→キャンセル→
  所有者記録付き再爆発)で復元。クリーパーは `Creeper#explode()` の本物のバニラ爆発、
  TNTもバニラ(発生源=モブ/ブロック自体で、着火者は免除されない)。
  キル加入は ExplosionSourceTracker(設置PDC+最後のパンチ記録+getIgniter)が担当。
- **死亡検知の新方式(デス画面・ローディング画面ゼロ)**: トーテムは完全バニラ
  (EntityResurrectEvent には触らない)。本当に死んだときだけ PlayerDeathEvent をキャンセル
  (Paper の cancel + setReviveHealth 契約)して蘇生 — combat-kill パケットも強制リスポーンも
  発生しないので「Loading terrain」画面は出ない。ProtocolLib のパケット抑制
  (DeathBridgePackets)は不要のため削除。

- **キット**: `/kit` 選択GUI、キット編集、プレビュー、金床リネーム(制限あり)、プリセット
- **Main Kits / Sub Kits の2分割**: 各キットは `kits.yml` の `category: MAIN|SUB` で
  どちらのセクションに出るか決まる(未設定=MAIN)。全キット選択GUI(デュエル/キュー/パーティ/看板キット)は
  **行1=Main Kits(大自然=ワイルドな鍛冶型 / Wild Armor Trim Smithing Template ヘッダー)**、
  **行2=Sub Kits(ネジ止め=ボルトの鍛冶型 / Bolt Armor Trim Smithing Template ヘッダー)** に分かれ、Mainが多い場合は行3-4に続く。
  統計(/stats)・プロフィール・チーム設定のキット cycling も Main→Sub 順。
  **順番は管理GUI(キット一覧でShift+クリック)で決められる** — 同じカテゴリ内でのみ
  入れ替わり、`kit-order` にカテゴリ別順序として永続化。管理GUIの設定画面にも
  Main/Subタイル(ワイルド/ボルトの鍛冶型)があり、クリックで所属セクションを切替
- **オリジナルキット**: `/originalkit` — 自分で編集して保存するカスタムキット。スロット別管理、差分(デフォルト比)保存、プリセットは免除
- **オリジナルキット専用部屋**: 編集は専用の物理部屋(クリエイティブ、他プレイヤーから非表示・当たり判定なし)。設定は `/ekitadmin spawn`(部屋の中で実行)+ 管理ツールで範囲選択して `/ekitadmin region`。部屋の「保存ボタン」(看板ボタン、置くと自動登録)で保存して退出。未設定時は編集に入れず案内メッセージのみ(インベントリは壊れない)
- **Ekit(イベントキット)**: `/ekit` + 管理者用編集/コピー/選択GUI
- 防具トリム(スミシング台GUI)、エンチャント/ポーション選択、ゴールデンヘッド、トーテム
- **カスタムシールド**: 管理GUIでパターン編集(最大6レイヤー)、カスタムモデルデータ配信
- ロビー機能アイテム(コンパス・離脱アイテム等)、アイテムフローガード

## プラットフォーム・統合

- **多言語対応**: 日本語・英語(米/英)・韓国語・中国語・スペイン語・フランス語の7言語。`/lang` で切替、初回参加時に言語選択GUI
- **Lunar Client**: Apollo リッチプレゼンス連携
- **Bedrock(Geyser)対応**: 参加検知、プラットフォーム別マッチング
- **TAB(プレイヤーリスト)**: 試合中はチーム別の縦列に自動整列(チーム順に列、列内は名前順、観戦者は下部)。少人数でも列が分かれるよう、各チーム列の間に**空白パディング**(透明な埋め草プレイヤー、実体なし・スキン/チャット/コマンドに影響なし)を自動挿入。チームカラー・ランクバッジ・チームマーカー表示、ロビープレイヤーは試合参加者から非表示。1.21.2+ のリスト順序インデックス+ProtocolLibで実現(`match.tab-columns-enabled`、パケットパッチャー系プラグインは自動検出して無効化、ProtocolLib未導入時は列分けのみで空白なし)
- **ProtocolLib**: カスタムモデルデータ・パケットレベルの見た目制御
